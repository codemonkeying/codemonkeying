Linux, networking and security. I build tools that fix problems I hit in my own lab, to learn, or both.

- **[proxmox-usb-hotplug](https://github.com/codemonkeying/proxmox-usb-hotplug)**: Proxmox can't hot-plug USB into running VMs. A daemon that does it from native resource mappings, with device pools, cluster awareness, GPU-following peripherals and exclusive PCI ownership.
- **[openwrt-mt76x8-usb](https://github.com/codemonkeying/openwrt-mt76x8-usb)**: the Pineapple Mk7 on stock OpenWrt is missing USB drivers and its USB port is dead. Vanilla OpenWrt with both fixed.
- **[mesh-433](https://github.com/codemonkeying/mesh-433)**: $2 radios are one-way and short-range. A self-healing mesh on Arduino hardware, with relay discovery, per-hop acks and failover.
- **[study](https://github.com/codemonkeying/study)**: cert study in the terminal. Finds your weak spots and drills them, with Network+, Security+ and Tech+ banks, timed mock exams and progress synced across machines and phone.
- **[lmap](https://github.com/codemonkeying/lmap)**: map data comes from many sources, formats and platforms. Download once, then export offline maps, topo sheets and QGIS projects in the format you need.
- **[lean-coder](https://github.com/codemonkeying/lean-coder)**: a lightweight terminal coding agent. Lean prompts, any LLM provider, local or remote, with background workers on different models.
